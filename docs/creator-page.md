# Страница «Ищем креаторов»

Страница: `public/creators/index.html`. Публичный адрес на текущем хостинге после загрузки: https://dexartteam.github.io/owaistudio/public/creators/.

## Установка

Содержимое архива нужно загрузить в корень репозитория `dexartteam/owaistudio`, сохранив папки `public`, `scripts` и `docs`. Существующие файлы `index.html` заменить. Сборка и установка зависимостей не нужны. Архив содержит только изменённые и новые файлы; остальные файлы сайта сохраняются.

Базовый коммит: `50f72fb314b4087079f9013c85d79be5f706bc51`.

## Что изменено

- Новая страница с приглашением, тремя форматами контента, условиями сотрудничества, порядком участия, FAQ и подготовкой письма.
- Оранжевая ссылка «Ищем креаторов» во всех 15 верхних меню, включая новую страницу. Относительные пути учитывают вложенность.
- Четыре новые фотографии с существующими персонажами OWAI. У каждого файла есть уменьшенная версия для адаптивной загрузки.
- Обновлён шаблон общей навигации в `scripts/update_navigation.py`.

Навигация подключает отдельный `creator-nav.css`. Контент новой страницы использует `creators.css` и `creators.js`; старые страницы не подключают эти два файла.

## Источник структуры и контакт

Референс: https://chatplace.io/ru/creator-league/ — последовательность «приглашение → форматы и выгоды → участие → вопросы → контакт». Дизайн, тексты и медиа созданы для OWAI. Ставки, выплаты за просмотры, реферальные условия, розыгрыши и отзывы ChatPlace не перенесены.

Адрес `hello@owai.studio` проверен на официальной странице https://owai.studio/legal/contact.html 18 сентября 2026 года. Условия сотрудничества предлагается согласовать индивидуально до начала работ.

## Как работает форма

Сайт статический. Кнопка «Составить письмо» собирает данные только в браузере и показывает текст, ссылку `mailto:` и кнопку копирования. Отправки на сервер нет. Пользователь отправляет письмо самостоятельно из почтового приложения. При недоступном Clipboard API текст выделяется для ручного копирования. При отключённом JavaScript остаётся прямой адрес электронной почты.

Проверка формы не отправляет реальных писем. Данные не записываются в localStorage, cookies или аналитику.

## Медиа и параметры генерации

Метод: встроенный `image_gen`, генерация с референсами персонажей, затем техническое уменьшение и WebP-сжатие (quality 83). Изображения не являются отзывами или фотографиями участников программы; на странице они помечены как AI-персонажи OWAI.

Общая постановка: фотореалистичная редакционная фотография; естественная кожа, дневной свет; палитра слоновой кости, графита, дерева и сдержанных оранжевых акцентов. Сохранить лицо и узнаваемые особенности персонажа из референса. Не добавлять надписи, логотипы, водяные знаки, интерфейсы, показатели просмотров, деньги или призы.
